# 地下の穹窿

[English](../README.md) · [简体中文](README.zh-CN.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Deutsch](README.de.md) · **日本語** · [Français](README.fr.md) · [Polski](README.pl.md) · [한국어](README.ko.md)

どこまでも続く塔を一人称視点で歩く探索ゲームです。出発点は度量衡の資料庫。引き出しが並ぶ木の渡り廊下から階段をたどると、潮汐の貯水槽や天文台、音叉の森に行き着きます。塔の住人はそれぞれ違う音を立てます。姿が見える前に、誰が近くにいるのか分かることもあります。

![資料庫の引き出しの間を、真鍮の手すりが付いた木の渡り廊下が通っている。](screenshots/archive.jpg)

*度量衡の資料庫*

## 起動方法

Linux 版と Windows 版はいずれも x86-64 用です。ゲームのデータは実行ファイルに含まれています。描画には Godot の Forward+ レンダラーを使用します。

- **Windows** — `build/LowerVaults.exe` をダブルクリックします。
- **Linux** — プロジェクトのディレクトリで次のコマンドを実行します。

```sh
chmod +x "build/Нижние своды.x86_64"
"./build/Нижние своды.x86_64"
```

## 操作

| 動作 | 操作方法 |
| --- | --- |
| 塔に入る | Enter、スペース、または「入る」ボタン |
| 歩く | WASD または矢印キー |
| 見回す | マウス |
| 走る | 移動中に Shift を押し続ける |
| 一時停止・再開 | Esc |
| 終了 | Esc →「ゲームを終了」 |

一時停止メニューでは、マウス感度、全体の音量、自分の足音の大きさを個別に調整できます。

## 言語設定

タイトル画面と一時停止メニューの右上から言語を選べます。変更すると、メニュー、操作ガイド、場所の名前がすぐに切り替わります。初回起動時はシステムの言語を使用し、対応していない場合は英語で表示します。選んだ言語は次回の起動時にも引き継がれます。このページの先頭に、対応する全10言語へのリンクがあります。

## ソースからのビルド

**Godot 4.7.1 stable** と同じバージョンのエクスポートテンプレートを使用します。テンプレートは **Editor → Manage Export Templates** からインストールできます。エディターで遊ぶには `project.godot` を開いて F5 を押してください。

両方のプラットフォーム向けにリリース版を作成するには、プロジェクトのルートで次のコマンドを実行します。`godot` はエディターの実行ファイルを指すようにしてください。

```sh
godot --headless --import
godot --headless --export-release "Linux"
godot --headless --export-release "Windows"
```

出力先は [export_presets.cfg](../export_presets.cfg) で設定します。原文はロシア語で、ほかの9言語の翻訳は [i18n](../i18n/) にあります。中国語・日本語・韓国語用のフォールバックフォントを同梱しています。[フォントのライセンス](../i18n/fonts/OFL.txt)。
