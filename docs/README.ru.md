Атмосферная прогулка от первого лица по бесконечной башне. Путь начинается в Архиве мер и весов. Лестницы ведут из каменных галерей в приливную цистерну, обсерваторию и лес камертонов. У каждого обитателя свой звук, по которому его можно узнать до встречи.

## Запуск

Распакуйте целиком архив для своей платформы x86-64. Библиотеки EOS должны лежать рядом с игрой. Для графики используется рендерер Godot Forward+.

- **Windows** — откройте `LowerVaults.exe` двойным щелчком.
- **Linux** — выполните команды в распакованной папке.

```sh
chmod +x LowerVaults.x86_64
./LowerVaults.x86_64
```

### Если Windows не даёт запустить игру

Сборка для Windows пока не подписана, поэтому Windows может не дать её запустить.

- **Microsoft Defender SmartScreen** показывает окно «Система Windows защитила ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом случае**.
- **Интеллектуальное управление приложениями** (Smart App Control) блокирует неподписанные программы, и запустить их нельзя. Его можно отключить: **Безопасность Windows → Управление приложениями и браузером → Параметры интеллектуального управления приложениями**. В некоторых версиях Windows 11 включить его обратно можно только переустановкой Windows. У сборки для Linux такого ограничения нет.

Мы подали заявку на бесплатный сертификат подписи кода в SignPath Foundation. Фонд выдаёт сертификаты только уже известным проектам, поэтому пока заявку отклонили. Подадим её снова, когда игра станет известнее.

## Как играть вместе

Выберите режим и начните прогулку. Настроенная сборка входит в сеть по идентификатору устройства и открывает комнату. Её код из шести символов виден в правом верхнем углу, например `K7Q-2MX`. Друзья вводят этот код на стартовом экране и нажимают **Войти по коду**. В коде зашиты режим и размер карты, поэтому все попадают в одну и ту же экспедицию. Комната вмещает до восьми игроков.

Состояние сети видно рядом с кодом. Попутчиков можно узнать по огоньку на плече. У каждого своё здоровье, реликвии, встречи с обитателями и финиш. Пауза сохраняет подключение. Если сеть недоступна, прогулку можно продолжать.

## Управление

| Действие | Управление |
| --- | --- |
| Начать прогулку | Выбрать режим или нажать Enter на выделенном режиме |
| Идти | WASD или стрелки |
| Осмотреться | Мышь |
| Бежать | Удерживать Shift при движении |
| Приостановить или продолжить прогулку | Esc |
| Выйти из игры | Esc → «Выйти из игры» |

В паузе можно настроить чувствительность мыши, общую громкость и громкость собственных шагов.

## Язык

Выберите язык в правом верхнем углу стартового экрана или меню паузы. Меню, подсказки и названия локаций переключаются сразу. При первом запуске игра использует язык системы, а если перевода для него нет — английский. Выбор игрока сохраняется между запусками. Все десять языков перечислены в начале страницы.

## Приватность

Когда начинается прогулка, игра подключается к Epic Online Services, чтобы найти попутчиков по коду комнаты. Вход анонимный, по идентификатору устройства. Игрокам в той же комнате передаются только ваше положение и направление взгляда. Других данных игра не отправляет. Соединение Epic обрабатывает по своей [политике конфиденциальности](https://www.epicgames.com/site/privacypolicy).

## Сборка из исходников

Для обеих платформ использовались Godot **4.7.1 stable** и шаблоны экспорта той же версии. Шаблоны можно установить в редакторе через меню **Editor → Manage Export Templates**. Чтобы запустить проект в редакторе, откройте `project.godot` и нажмите F5.

Для выпуска обеих сборок выполните из корня проекта следующие команды. Команда `godot` должна указывать на исполняемый файл редактора.

```sh
python3 tools/install_eos.py
godot --headless --import
godot --headless --export-release "Linux"
godot --headless --export-release "Windows"
```

Пути назначения заданы в [export_presets.cfg](../export_presets.cfg). Русские строки служат оригиналом, девять переводов лежат в [i18n](../i18n/). В игру включён резервный шрифт для китайского, японского и корейского. [Лицензия шрифта](../i18n/fonts/OFL.txt).

### Настройка EOS для сетевой сборки

1. Войдите в [Epic Developer Portal](https://dev.epicgames.com/portal/) и создайте продукт **The Lower Vaults** или откройте существующий.
2. В **Product Settings → Clients** создайте политику типа **Peer2Peer**, затем игровой клиент с этой политикой. [Инструкция Epic](https://dev.epicgames.com/community/learning/tutorials/JGKP/unreal-engine-eos-p2p-lobbies-and-voice).
3. Скопируйте [шаблон](../network/eos.cfg.example) в `network/eos.cfg`. Укажите Product ID, Sandbox ID, Deployment ID, Client ID и Client Secret этого игрового клиента. Git игнорирует заполненный файл.
4. Выполните экспорт. Файл войдёт в сборку. В уже готовой сборке можно положить заполненный `eos.cfg` рядом с исполняемым файлом — он получит приоритет. Раздавайте папку игры целиком.
5. Запустите игру на двух устройствах, начните прогулку на одном, введите её код на другом и отойдите от точки старта. Убедитесь, что движения видны на обоих экранах, а после выхода одного игрока его фигура исчезает у другого.

Для автоматической проверки выполните команду из настроенного проекта на двух устройствах. Имя проверки должно совпадать. На втором устройстве замените последнюю букву на `B`. Каждая копия завершится успешно, когда получит подтверждение своей позиции от второй через EOS.

```sh
godot --headless --script tests/eos_peer.gd -- vaults-test A
```

Если Windows сообщает об отсутствии MSVCP140 или VCRUNTIME140, установите [Microsoft Visual C++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe).
