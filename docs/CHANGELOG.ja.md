## [0.2.0](https://github.com/ArcheeNic/lower-vaults/releases/tag/v0.2.0) — 2026-11-25

- **通常モード。** プレイのたびに、モジュール式の部屋から塔が新しく組み上がります。日の光が漏れる扉を見つければ脱出できます。**サンドボックス**では、度量衡の資料庫から始まる自由な散策を引き続き楽しめます。
- **住人の接触。** 接触に影響が出るようになりました。点灯夫は明かりを消し、潜水夫は面に水を満たし、巡礼者は出発点へ連れ戻し、紡錘は体の向きを変えます。ほかにもあります。
- **拾得物。** 琥珀の印章は接触を一度だけ防ぎます。砂時計は住人を45秒間遠ざけます。
- **生きた広間。** 機械が動き、魚群や虫の群れが漂い、蒸気が噴き出します。部屋ごとに鐘、時計、音叉、水、通気口の音があります。
- 深度フォグがカメラの描画距離に合わせて変わるようになりました。

## [0.1.0](https://github.com/ArcheeNic/lower-vaults/releases/tag/v0.1.0) — 2026-11-24

- 果てしない塔を一人称視点で歩く散策。三つの舞台が階層間の階段でつながっています。
- 非ユークリッド的な通路と局所的な重力。壁を歩いて天井まで上がれます。
- それぞれ固有の音を持つ住人たちと、追跡者。
- 10の表示言語。タイトル画面とポーズメニューで切り替えられます。
- Windows と Linux 向けの単体実行ファイル。
